# Genre Rules

- Default genre: Gothic Fantasy (configurable per project).
- Lean into genre conventions while finding fresh angles.
- Gothic: dark atmosphere, psychological tension, secrets, decaying grandeur.
- Fantasy: internal magic system logic must remain consistent. No deus ex machina.
- Blend genres thoughtfully — the dominant genre sets the tone, secondary genre adds texture.
- Respect reader expectations: mysteries need clues, romances need chemistry, thrillers need stakes.
