# Character Consistency Skill

Before writing any scene involving characters:

1. **Retrieve** all stored passages mentioning each character in the scene.
2. **Extract** from retrieved passages:
   - Physical description (eye color, height, distinguishing features)
   - Personality traits (temperament, speech patterns, quirks)
   - Relationships with other characters present
   - Current emotional state and story arc position
3. **Verify** no contradictions exist between retrieved traits and planned content.
4. **Inject** character profiles into the generation context.
5. **After generation**, check the output for consistency with retrieved profiles.

## Character Profile Format
```
[Character Name]
- Appearance: ...
- Personality: ...
- Voice/speech patterns: ...
- Relationships: ...
- Current arc status: ...
- Things that must NOT change: ...
```
